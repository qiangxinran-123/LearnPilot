# M8-3 掌握度趋势与学习历史

## 开发前检查

当前仓库已实现 M8-1/2 的课程总览和知识点比较，也已存在 M8-3 趋势与学习历史，以及先前实现的 M8-4 风险区域；本轮保留后者，未继续开发风险功能。项目未引入 ECharts，现有趋势使用响应式 SVG，故复用现有实现而不新增依赖。

已存在课程范围的 progress/trend 与 progress/history 只读接口、共享 API Client、课程选择状态、加载和错误组件以及既有测试。M5 MasteryHistory 保存带时间、指纹和算法版本的历史结果；M7 学习会话有完成状态与时间。历史接口未提供可可靠关联的本次学习前后掌握度，因此不推断变化。

## 数据与交互

- 趋势沿用后端当前课程活跃叶子节点口径：当时已评估节点等权平均，展示覆盖率；按记录时间及记录 ID 排序，图结构或算法不兼容时断开。仅使用真实历史记录，不回填虚构数据；7 天、30 天、全部由现有服务筛选。
- 历史沿用服务端当前用户和课程过滤、时间倒序与游标分页，包含已提交初始诊断及已完成学习会话，不包含未完成或中断会话；每个事件使用来源类型和 ID。
- 本轮修复单条历史数据没有显示点的问题，并在异常时间或分数时排除无效点且不跨异常数据连线。鼠标悬停或键盘聚焦可查看具体时间、掌握度与覆盖率；单点不会制造第二个点。
- 学习会话明确显示“暂无可确认的掌握度变化记录”，不把时间相邻视为因果。时间统一按中文格式展示；移动端纵轴刻度保持可读。
- 后端本轮未修改；未改动 M5、M6、M7 算法、数据库或依赖。此前其他阶段未提交修改均予保留。

## 已知限制与阶段结论

历史只能从现有 M5 快照记录开始展示，不能恢复此前未记录的历史；图结构在记录之间变化后又还原的情况无法完整识别。Session 级可靠前后掌握度关联尚未提供，故仅说明无法确认，不归因。
