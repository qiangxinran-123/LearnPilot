# LearnPilot V0.1 最终验收清单

当前状态：**V0.1 发布范围已完成**

LearnPilot V0.1 是一个面向大学生的 AI 学习资料管理与复习辅助后端原型。本清单用于比赛评审、仓库交付和后续版本接手。

## 已完成能力

| 模块 | 验收内容 | 结果 |
| --- | --- | --- |
| 应用启动 | FastAPI 应用可从 `backend.main:app` 启动。 | 通过 |
| 课程接口 | 可查询课程列表和课程详情。 | 通过 |
| 资料接口 | 可查询课程资料并通过 JSON API 创建资料。 | 通过 |
| 数据持久化 | 资料写回 `courses.json`，重启服务后仍然可读。 | 通过 |
| 文件上传 | 支持常见课程资料格式，并按课程保存到本地目录。 | 通过 |
| 文本提取 | `.txt`、`.md` 自动保存预览、字符数和提取状态。 | 通过 |
| mock 摘要 | 有可用文本时生成并保存本地 mock AI 摘要。 | 通过 |
| 资料搜索 | 可按资料元数据、提取文本和 mock 摘要搜索。 | 通过 |
| 学习卡片 | 有可用文本时生成并保存 3 张 mock 复习卡片。 | 通过 |
| 兼容性 | 旧资料缺少新增字段时仍然可以被 GET 接口读取。 | 通过 |
| 项目文档 | README、开发日志、API 总览和 Demo 脚本齐全。 | 通过 |
| 仓库卫生 | 虚拟环境、缓存、环境文件和真实上传文件不会提交。 | 通过 |

## 当前限制

- 暂未接入真实 LLM，摘要和学习卡片均为本地 mock AI 实现。
- 暂未实现前端页面，当前主要通过 FastAPI `/docs` 演示。
- 暂未使用数据库，课程和资料数据保存在本地 JSON 文件中。
- 暂未使用向量数据库、Embedding 或 RAG。
- 当前仅支持 `.txt` 和 `.md` 正文提取，PDF、PowerPoint、Word 文件暂时只保存不解析。
- 暂未实现用户认证、资料权限、多用户协作和高并发生产能力。

## V0.2 规划

- 接入真实 LLM，替换 mock 摘要和卡片服务。
- 增加 PDF、PowerPoint、Word 文本提取。
- 使用数据库替代本地 JSON 存储。
- 引入 Embedding、RAG 和向量数据库。
- 开发学生端前端页面，支持课程资料、搜索和复习卡片可视化。
- 增加用户认证、资料归属、收藏和学习进度管理。

## 发布判断

当完整测试通过、仓库中只保留有意提交的源代码、示例数据和文档，并且最新提交已推送到 `origin/main` 时，LearnPilot V0.1 可以标记为完成。
