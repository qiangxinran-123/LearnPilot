# LearnPilot V0.3 比赛演示脚本

建议时长：4-6 分钟。

本次演示围绕一个学生用户故事展开：学生把一份课程资料上传到 LearnPilot，生成摘要和复习卡片，再搜索知识点完成复习。当前摘要和卡片由本地 mock AI 生成，不代表已接入真实大模型。

## 1. 项目简介

讲解词：

> LearnPilot 是一个帮助大学生把课程资料快速整理成摘要、复习卡片和可搜索知识库的 AI 学习助手。当前版本不继续堆叠功能，而是把体验收束为“选择课程、上传资料、生成学习包、搜索复习”这一条学习闭环。

打开首页 `http://127.0.0.1:8000`。说明页面由 FastAPI 托管的原生 HTML、CSS、JavaScript 构成，不需要前端构建工具。

## 2. 选择课程

1. 指向页面顶部的四步流程。
2. 在左侧“选择课程”中点击 Machine Learning / 机器学习。
3. 观察当前课程标题、资料列表和上传目标同步更新。

讲解词：

> 学习从课程范围开始。学生不必面对 API 或数据表，而是在自己的课程资料里完成后续整理和复习。

## 3. 查看已有资料

1. 点击 Gradient Descent Notes。
2. 展示右侧“学习包”中的资料类型、解析状态、文本预览、智能摘要和复习卡片。
3. 指出“已解析多少字”是资料状态，不是单独需要操作的功能。

讲解词：

> 系统把文件解析结果收进学习资料详情，学生只需关心这份资料能否用于学习包生成。

## 4. 上传一份资料

提前准备一个 `.txt` 或 `.md` 文件，例如：

```text
Gradient descent updates model parameters in the opposite direction of the gradient.
A suitable learning rate helps the model converge without overshooting.
```

1. 保持课程已选中。
2. 在“上传课程资料”中选择文件。
3. 确认提示“将上传到：Machine Learning / 机器学习”。
4. 点击“上传资料”。
5. 展示新资料自动出现在列表，并被选中。

讲解词：

> 上传后的资料和文件会写回本地 JSON。TXT 和 MD 会自动解析正文，所以新资料会立即显示解析字数和文本预览。

## 5. 生成学习包

1. 选中新上传的资料。
2. 点击右侧主按钮“生成学习包”。
3. 观察状态先显示生成摘要，再显示生成复习卡片。
4. 生成后展示智能摘要与三张复习卡片。
5. 简要展示辅助入口“只生成摘要”和“只生成卡片”，说明主流程优先使用“生成学习包”。

讲解词：

> 这里没有新增后端接口。前端按顺序调用已有摘要和卡片接口，把两个技术步骤组合成学生易理解的一次操作。当前使用本地 mock AI，不调用外部 API。

## 6. 搜索复习

1. 在“搜索知识点”输入 `gradient`。
2. 点击“搜索复习”，展示结果数量和命中资料。
3. 点击结果，右侧显示对应资料详情。
4. 点击“返回课程资料”，恢复当前课程列表。
5. 可切换到计算机组成原理搜索 `cache`，或数据结构搜索 `linked list`。

讲解词：

> 学生复习时不必重新翻找文件。搜索会覆盖资料标题、文件名、正文预览和摘要，并限制在当前课程范围内。

## 7. 总结与 API 文档

打开 `http://127.0.0.1:8000/docs`，作为接口结构补充。

讲解词：

> LearnPilot 已实现从资料上传、文本提取、持久化，到摘要、复习卡片和知识点搜索的完整可演示闭环。下一步会接入真实 LLM、RAG 和向量数据库，但当前版本会明确标注为 mock AI 原型。
