## 二、实现动态诊断

每次新建诊断时：

1. 读取学生的历史作答题目。
2. 保证必需知识节点覆盖。
3. 优先选择学生未做过的合格题。
4. 对薄弱节点给予合理的出题优先级，但不能破坏核心节点覆盖。
5. 对题量不足的节点，调用现有 DeepSeek 生成服务批量补充新候选。
6. 对生成结果进行必要质量校验。
7. 自动准入和人工验证状态必须明确区分。
8. 不允许不经说明反复返回全部旧题。
9. 内容近似重复的题不得作为新的独立证据。

如果 API 失败或没有可用新题：

明确提示原因，优先使用其他未做过的合格题。

不得无限 Loading，也不得因为题目 ID 不同就错误增加有效 Evidence。

## 三、实现自适应连续练习

当学生从 Recommendation 进入 Learning Session：

1. 根据推荐知识节点获取新的练习题。
2. 优先选择未完成过的合格题。
3. 若题池不足，调用现有 DeepSeek 服务批量补题。
4. 学生提交答案后，正常产生 Evidence。
5. 重新计算 Mastery / Confidence。
6. 判断该节点是否达到现有掌握标准。
7. 尚未达到标准，则展示不同的新题继续练习。
8. 已达到标准，则完成当前知识节点并刷新推荐，进入下一个符合先修关系的节点。
9. 没有合法下一推荐时，展示合理的学习完成或待复习状态。
10. 练习题暂时不足时，提供明确提示和 Tutor 辅导入口，不得无限重复同题刷分。

禁止通过直接修改数据库来制造掌握度或学习进展。

## 四、掌握标准

优先复用现有 Mastery / Confidence 算法。

- 至少 3 条有效且内容不同的独立 Evidence。
- Mastery 达到 0.80。
- Confidence 达到现有系统可判定的可信等级。
- 最近 2 道不同题目正确。

必须符合现有证据模型。

不能简单把回答正确次数当成 Mastery。

避免重复答题无限刷高掌握度。
