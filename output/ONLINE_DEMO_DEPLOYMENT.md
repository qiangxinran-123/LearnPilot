# LearnPilot 免费在线演示准备

## 当前状态

本文件描述准备中的在线模式；截至本次本地验收，尚未在 Render 部署，也没有可以分享的公网链接。在线分支基于参赛候选版本，原开发数据库、上传资料和 main 分支不受影响。

## 评委体验

每个浏览器首次访问时获得服务端签名的 HttpOnly 会话 Cookie，并从已审核的演示快照创建独立的 SQLite 和上传目录。课程、知识图、题库初始相同；作答、掌握、计划、上传和课程删除只影响当前浏览器会话，不能通过修改用户 ID 读取其他会话。

评委数据**不是只保存在电脑上**：浏览器保留会话 Cookie，服务端临时保存该会话的数据库和文件。免费服务重启或休眠后，这些临时学习记录会丢失；下次访问自动重新获得干净的演示课程。不同浏览器或清除 Cookie 后会得到新会话。同一浏览器共享 Cookie 的使用者会看到同一会话。

## 费用与限制

`render.yaml` 计划创建一个免费 Web 服务和一个免费的 PostgreSQL 控制数据库，均在 Singapore。Web 服务空闲后会休眠，首次唤醒可能较慢；临时文件会在重启和休眠后丢失。免费 PostgreSQL 通常 30 天到期，不存学习内容，仅保存随机会话标识、请求计数和时间，用于跨重启维持模型调用预算。免费资源和网络流量仍受 Render 当前政策约束，超额是否产生费用应以账号页面为准。

默认最多累计创建 30 个会话（该上限不会因服务休眠自动重置）、每会话 30 次模型调用、总计 300 次、每会话每分钟 20 次模型调用，每分钟 180 次 API 请求；单个上传文件上限 5 MiB，每个会话累计上传请求上限 50 MiB，总累计上传请求上限 250 MiB。模型调用计数在网络请求前原子保留，包含失败及重试；上传限额按请求预留，失败也可能消耗额度。额度耗尽后模型功能会拒绝新请求，但不影响已有题库诊断等本地逻辑；限制可按评委人数和比赛预算调整。模型调用由 DeepSeek 单独计费，调用次数不是费用上限；应在模型平台监控用量并设置可用的账户额度控制。

## 密钥

Render 生成独立的会话签名密钥。比赛专用 DeepSeek API Key 在 Render 的安全环境变量页面填写 `LLM_API_KEY`，不要写入代码、前端、截图、日志或公开聊天。默认模型 `deepseek-flash` 和 `https://api.deepseek.com` 在既有独立验收中曾使用；最终以比赛 Key 的可用模型及在线测试为准。

## 本地验证结果

- 两位独立评委测试：A 创建课程、完成诊断和计划后，B 看不到 A 的课程或诊断；伪造 Cookie 返回 403。
- 用户上传材料并启动后台知识建模的隔离测试通过，使用 mock 模型，不冒充真实调用。
- 模拟 Provider 的真实 HTTP 调用路径验证了会话与全局调用上限；并发超过额度会拒绝网络调用。
- 使用隔离的真实本地 PostgreSQL 验证：5 并发请求仅允许配置的 3 次；重新建立临时课程目录后额度仍被拒绝，已签名会话恢复到干净快照。
- 浏览器在本机在线模式完成课程、来源、诊断和计划；第二个独立浏览器看不到第一位评委的诊断。
- 后端相关回归 45 项通过，前端生产构建、Python 静态检查通过。本机没有 Docker 或 Render CLI，官方 Schema 下载超时；Docker 构建和 Render 配置尚未完成平台验证。
- 线上真实 DeepSeek、HTTPS Cookie、免费资源可用性、评委地区访问速度和故障恢复仍需在正式部署后验证；不能保证大文件或高并发。

## 发布前

1. 复核在线分支和本文件，并将该分支提供给 Render 可访问的 Git 仓库。不要覆盖已有 main 分支或包含 .env。
2. 在 Render 先规划 `render.yaml`，确认是免费 Web 服务与免费控制数据库，再按平台流程审批。
3. 按 Render 安全配置流程由资源所有者填写比赛专用 `LLM_API_KEY`；不应把密钥提交到仓库。
4. 部署后从不同浏览器验证课程、诊断隔离、真实问答与建模、额度拒绝、HTTPS、资料来源和休眠恢复。只有实际验证成功后才能分享真实网址。
5. 比赛期间留意免费数据库 30 天期限、服务休眠与用量；赛后禁用服务并轮换比赛 Key。

参考：[Render 免费资源限制](https://render.com/docs/free)、[Render 环境变量与密钥](https://render.com/docs/configure-environment-variables)。
